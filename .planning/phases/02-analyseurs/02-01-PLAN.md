<decisions>
- Les métriques sont calculées sur le graphe **complet** ; le filtrage n'intervient qu'à l'affichage (décision utilisateur, phase 1).
- I = Ce / (Ca + Ce) avec Ce **interne** uniquement, pour que Ca et Ce aient le même périmètre. Le nombre de dépendances externes est exposé à part (`externalCount`). I = 0 quand Ca + Ce = 0.
- Aucune valeur arrondie dans le cœur : des `float` bruts, l'arrondi revient aux renderers.
- Un composant regroupe des classes. Résolution : la première définition nommée (glob) qui correspond l'emporte, dans l'ordre de déclaration ; sinon, repli sur les N premiers segments du namespace (N = 2 par défaut, `App\Domain\Foo\Bar` → `App\Domain`).
- Métriques composant selon Martin : Nc = classes (hors traits), Na = interfaces + classes abstraites, A = Na / Nc (0 si Nc = 0) ; Ca = nombre de classes **hors** du composant qui dépendent d'une de ses classes ; Ce = nombre de classes **hors** du composant dont dépend une de ses classes ; I = Ce / (Ca + Ce) ; D = |A + I − 1|.
</decisions>
