<decisions>
- Fichier JSON versionné, lisible et diffable : `{ "schema": 1, "violations": [ { "fingerprint": "...", "message": "..." } ] }`, trié par empreinte. Le `message` est informatif ; seule l'empreinte sert à la comparaison.
- Nom par défaut : `dependencies-baseline.json` à la racine.
- Une entrée de baseline qui ne correspond plus à aucune violation est **obsolète** : signalée (compteur + liste en JSON), jamais bloquante.
- `--generate-baseline` écrit le fichier avec **toutes** les violations courantes et retourne 0, quel que soit le résultat.
</decisions>
