<decisions>
- Signature : `analyze {paths?*} {--config=} {--report=} {--format=table} {--output=} {--only=} {--exclude=}`.
- Résolution : `--config` sinon `dependencies.php` à la racine (cwd) sinon `Config::make()`. Les `paths` passés en argument remplacent ceux de la config ; `--only` / `--exclude` (listes séparées par des virgules) remplacent `only` / `ignore`.
- Codes de sortie : `0` succès ; `2` erreur (config invalide, chemin inexistant, section ou format inconnu, aucun chemin). Le code `1` (violations) arrive en phase 4. Constantes nommées dans la commande.
- `--output=fichier` écrit le rendu dans le fichier et affiche une ligne de confirmation ; sinon sortie standard via `$this->output->write()` (pas de `echo`).
- Pas d'animation ni de bannière (`hello()` des anciens presenters) : la sortie JSON doit rester exploitable telle quelle.
</decisions>
